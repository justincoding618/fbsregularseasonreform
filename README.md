# Division I FBS Regular Season Reform

An interactive web application exploring how the regular season can be reformed regardless of conference realignment.

# Features

- A main ideal scenario of the plan
- Analysis of other scenarios that can happen
- Demonstrations and Examples of Different Scenarios

# Tech Stack

- HTML5, CSS3, JavaScript
